# Divine Arsenal animation binary bundle

This transfer bundle contains the original Library GIF/MP4 exports and the processed derivatives catalogued on 2026-11-13.

- `source/gif/` — GIF assets not named as the 24fps/5s or doubled-FPS derivatives.
- `source/mp4/` — original/combined MP4 assets.
- `derived/gif/` — 24fps/5s and doubled-FPS GIF derivatives.
- `derived/mp4/` — 24fps/5s MP4 derivatives.
- `manifest.json` — per-file SHA-256 and size.

Do not overwrite originals. Use Git LFS for the media payloads. Verify every file against `manifest.json` after extraction.
