# Incremental target

Retain FastAPI, SQLite profiles, existing astronomy and plain browser JS.
Add bounded Pydantic research records, packaged catalogue JSON, pure Psalter,
language, IIIF and diagram services behind a research API router. Keep all
imports untrusted, never execute source content, and never fetch imported URLs
server-side. Test provenance/rights before expanding the interface.

Research data and personal data remain separate. Edition coordinates are
explicit; chapter mappings may be many-to-many and never imply verse alignment.
Generated mathematical diagrams are RECONSTRUCTION, never historical facsimiles.
Fresh research/rights review, full text, Enochian inventory and institutional
viewer verification remain gated on evidence availability.
