# Rights register

| Material | State | Bundled? |
|---|---|---|
| Project-authored catalogue summaries, schemas, index and algorithms | MIT | Yes |
| Project-original TEI phrase and synthetic IIIF/provenance fixtures | MIT / explicit CC0 metadata fixture | Yes |
| Historical texts / modern translations | UNKNOWN per edition; no clearance inferred | No |
| Institutional scans, photographs, plates and glyph charts | UNKNOWN per asset | No |
| User photos / inscriptions / private personal data | Private; outside public corpus | No |
| Generated SVG orientation | Original mathematical RECONSTRUCTION, MIT | Generated on request |

Every source has independent metadata/text/image rights fields. Supplied research
reports some public-domain underlying works; this is not a grant for every
translation, scan, typography, territory or provider. No 150-body Psalter is
invented or bundled. The KJV button opens an external provider and conveys no
redistribution licence. Text-provider integration is BLOCKED pending inspected,
rights-cleared edition metadata and territorial review.

Imported IIIF rights statements are displayed as supplied, not legally certified.
Image loading is explicit; validation never downloads anything. The adapter
accepts JPEG/PNG only and a fixed institutional host allowlist. No copyrighted
institutional fixture is substituted for the synthetic test manifest.
