# Contributor operating contract

Observe → Verify → Reconcile → Improve → Test → Record.

- Keep historic FR3K source and private birth profiles out of this public repository.
- Label astronomical numerical outputs CALCULATION; occult interpretation SYMBOLIC, not proven causal prediction.
- No birth-derived privileges or agent roles. Ask users what their agents should accomplish.
- All global agent files, connectors, hosted accounts and external writes require explicit approval.
- Never run self-mutating jobs by default; no duplicated schedulers.
- Add numerical reference vectors and threat-model tests before announcing production readiness.
- Never equate a Git commit, running service, green tests or simulated steps with verified real usage.
